# Painel de dados do HUPE

Este painel apresenta dados de desempenho do ambulatório do Hospital Universitário Pedro Ernesto (HUPE), referentes aos anos de 2021 a 2024.

## O que você encontra

- **Profissionais:** quantidade por especialidade, tipo de vínculo e profissionais não médicos.
- **Relatórios anuais:** gráficos e comparações por especialidade de atendimentos e exames. Os relatórios de 2021, 2023 e 2024 também mostram tratamentos terapêuticos.
- **Detalhamento por período:** visualização dos dados por quadrimestre e consulta do desempenho de especialidades selecionadas.
